Models Used

Four baseline classifiers combined into one Soft Voting Ensemble.

Logistic Regression

A linear classifier that estimates the log-odds of high risk using a sigmoid function. Provides well-calibrated probability output.

Decision Tree

Builds a flowchart-like tree by splitting on features that reduce impurity. Easily interpretable but can overfit on deep trees.

Random Forest

An ensemble of 100 decision trees trained on bootstrap samples. More stable than a single tree and provides feature importance rankings.

Support Vector Machine

Finds a maximum-margin hyperplane in high-dimensional space using an RBF kernel. Probabilities estimated via Platt scaling.

Soft Voting Ensemble

The Ensemble takes the average of predicted class probabilities from all four models and classifies based on which class receives the higher combined probability. This often produces a more consistent result than any single model alone.
