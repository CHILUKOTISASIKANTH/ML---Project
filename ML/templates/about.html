About the Project

An overview of the system design, data, models, and limitations.

Project Overview

The Smart Disease Risk Prediction System is a machine learning classification project built with Python, Flask, and scikit-learn. It takes 11 patient health measurements as input and returns a binary classification — Low Risk or High Risk — based on patterns learned from a synthetic training dataset.

The project demonstrates a complete end-to-end machine learning pipeline: data generation, preprocessing, model training, evaluation, and deployment as a web application.

Input Parameters

The system uses exactly 11 input features:

# Feature Type Description
1 age Numerical Patient age in years
2 gender Categorical Male, Female, Other
3 blood_pressure Numerical Current systolic blood pressure reading (mmHg vital sign)
4 heart_rate Numerical Resting heart rate (bpm)
5 glucose Numerical Current fasting blood glucose level (mg/dL laboratory biomarker)
6 cholesterol Numerical Total cholesterol (mg/dL)
7 bmi Numerical Body Mass Index (kg/m²)
8 smoking Categorical Never, Former, Current
9 physical_activity Categorical Low, Moderate, High
10 family_history Categorical No, Yes
11 heart_disease Categorical Prior heart disease: No, Yes
— target Binary Target 0 = Low Risk, 1 = High Risk

Machine Learning Approach

Logistic Regression

A linear model that estimates the probability of High Risk using the logistic sigmoid function. It produces well-calibrated probability outputs and is a useful baseline for binary classification.

Decision Tree

A non-parametric model that recursively partitions the feature space based on Gini impurity. Tree depth is capped at 5 to limit overfitting. The resulting structure can be interpreted as a decision flowchart.

Random Forest

An ensemble of 100 independent decision trees, each trained on a random bootstrap sample of the data. Random feature selection at each split reduces correlation between trees. Random Forest also produces feature importance rankings (Gini importance).

Support Vector Machine (SVM)

Finds an optimal separating hyperplane with maximum margin in a transformed feature space using an RBF kernel. Probabilities are estimated via Platt scaling.

Soft Voting Ensemble

Combines the four individual models by averaging their predicted class probabilities. The final label is the class with the higher average probability. This approach tends to smooth out individual model errors, though it does not guarantee better performance on every dataset.

Data Processing

The preprocessing pipeline is built with scikit-learn:

  • Split first: Data is split into 80% training and 20% test sets before any transformation is applied, to prevent data leakage.
  • Numerical columns (age, blood_pressure, heart_rate, glucose, cholesterol, bmi): Missing values are filled with the training median; then Standard Scaled (z-score normalisation).
  • Categorical columns (gender, smoking, physical_activity, family_history, heart_disease): Missing values are filled with the most frequent category; then One-Hot Encoded.
  • No leakage: Scaler and encoder statistics are computed only on training data and applied to the test set.

Dataset

The dataset is synthetically generated (1,500 records, random_state=42). Patient values are drawn from realistic statistical distributions, and the binary target is derived from a weighted risk score that accounts for combinations of age, blood pressure, glucose, BMI, smoking, physical activity, family history, and prior heart disease.

The dataset is not derived from real patient records and should not be used to draw clinical conclusions.

Model Evaluation

All metrics are computed on the held-out 20% test set (approximately 300 samples) that was not used during training:

  • Accuracy — proportion of correctly classified records.
  • Precision — of all High Risk predictions, how many were correct.
  • Recall — of all actual High Risk records, how many were correctly found.
  • F1 Score — harmonic mean of precision and recall.
  • ROC-AUC — area under the ROC curve, measuring ranking ability.

All metrics are computed programmatically; no values have been manually specified.

Limitations

  • The training data is synthetic. Real-world patterns may differ from what was learned here.
  • Only 11 features are used. Many other factors that influence cardiovascular risk are not captured.
  • The output is a classification result, not a clinical assessment. It should not be used to make health decisions.
  • Model performance depends on how closely new inputs resemble the training distribution.

Technology Stack

  • Backend: Python 3, Flask
  • Machine Learning: scikit-learn (Logistic Regression, Decision Tree, Random Forest, SVM, VotingClassifier)
  • Data: pandas, NumPy
  • Visualisation: matplotlib, seaborn
  • Persistence: joblib
  • Frontend: HTML, CSS, JavaScript (no frameworks)
